# Cabina

Velocímetro configurable para iPhone (web app instalable). Usa el GPS para velocidad, rumbo y altitud, y los sensores de movimiento para brújula, horizonte artificial y fuerza G.

## Cabinas
- **Deportivo**: arco de velocidad digital, altitud, viaje, máxima, promedio, tiempo y medidor de fuerza G.
- **Clásico**: velocímetro de aguja con odómetro.
- **Cabina Tren / Cabina Auto / Cabina Avión**: usan la cámara trasera como parabrisas, con el panel de instrumentos abajo (en avión, además, simbología HUD sobre la imagen). Sin cámara muestran un paisaje simulado.
- **Avión PFD**: pantalla tipo PFD con cinta de velocidad (kt), altímetro (ft), horizonte artificial, alabeo, rumbo y velocidad vertical.
- **HUD**: número grande y brillante; modo espejo para reflejarlo en el parabrisas.
- **Running / Bici**: ritmo actual y medio, distancia, tiempo, desnivel positivo, con pausa y reinicio.

Desliza a los lados para cambiar de cabina. En Ajustes: escala máxima (automática o fija hasta 500 km/h), unidades, alerta de velocidad con sonido, color, suavizado, pantalla siempre encendida, modo demo y calibración del horizonte.

## Instalar en el iPhone
1. Publica el repositorio con GitHub Pages (Settings › Pages › Deploy from branch › `main` / root).
2. Abre la URL en Safari › Compartir › **Agregar a pantalla de inicio**.
3. Abre la app desde el ícono y toca **Comenzar** para dar permisos de ubicación y movimiento.

Las mediciones son referenciales y no reemplazan instrumentos del vehículo.
